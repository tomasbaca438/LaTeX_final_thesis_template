Main LaTeX source file for the final thesis presentation. Compilation is performed using **LuaLaTeX**, the text is typeset in **Source Serif 4**, and the mathematical part uses **Cambria Math**. The bibliography is processed using **Biber**.

-------------------------------------------------------------------------------

# Usage Guide

## Requirements

- **Compiler:** LuaLaTeX  
- **Bibliography system:** Biber

Recommended editor:

- **TeXStudio:** https://www.texstudio.org

-------------------------------------------------------------------------------

## Perl Installation

To ensure proper functionality of **Biber**, Perl must be installed.

Installation packages:

- https://www.perl.org/get.html

### Windows

Recommended distribution:

- **Strawberry Perl**

### Linux and macOS

Perl is typically included as part of the operating system.

-------------------------------------------------------------------------------

## LaTeX Distribution Installation

A LaTeX distribution provides:

- compilers,  
- packages,  
- dependency management,  
- tools for creating documents.

Recommended distribution:

- **MiKTeX:** https://miktex.org

During installation, set:

Install missing packages on-the-fly = Yes

-------------------------------------------------------------------------------

## TeXStudio Configuration

In the settings, enable:

Advanced Options

Then navigate to:

Build → Meta Commands → Build & View

and set:

txs:///lualatex |
txs:///biber |
txs:///makeglossaries |
txs:///lualatex |
txs:///lualatex |
txs:///view

Store bibliography sources in:

-------------------------------------------------------------------------------

## Recommended Tool for Bibliography Management

### JabRef

https://www.jabref.org/#download

It is recommended to run:

Quality → Check Integrity

The `.bib` file should contain only the following warnings:

- *Journal not found in abbreviation list*  
- *Citation key deviates from generated key*

# Troubleshooting

If you encounter compilation issues:

1. Check the `.bib` file.  
2. Remove problematic characters.  
3. Remove HTML tags or invalid content.

Common problematic strings include:

<a  
</a>  
href=  
target=  
rel=  
class=  
data-lexical  
_  
&  
#  
``  
$  
#:~:text=  
<script  
<div  
<span  
<strong  
<i>  
</i>  
<b>  
</b>

These characters and tags may cause issues when compiling with LuaLaTeX.
